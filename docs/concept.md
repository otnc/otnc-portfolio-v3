# コンセプトとデザイン

## 月夜のネットサーフィン

このサイトは、よく晴れた夜の海を、深夜のインターネットのウィンドウ越しに眺めるイメージで作っています。

- スクロールすると、沖から水面、波間、波打ち際へと岸に近づいていきます。ページの背景は下へ行くほど少し明るい青になり、最後は月明かりの砂浜で終わります。
- 内容は古い OS のウィンドウ (タイトルバー、`_ □ ×` のボタン、ドットの枠) に入れます。ウィンドウは画面に入ったとき、点線の枠が広がってから開きます。
- リンクは深夜のインターネットらしく、未訪問が水色、訪問済みが紫です。

## ページの流れ

| 順番 | 場所 | 中身 |
| --- | --- | --- |
| 1 | 沖 (ヒーロー) | 夜空、流れ星、ドットの月、水面の月の反射、ディザの波、自分のアイコン、名前、キャッチコピー、SNS アイコン |
| 2 | バナー | 横に流れるメッセージ |
| 3 | 水面 | `about.txt` (自己紹介)、`/otnc/works/` (作品) |
| 4 | 波間 | ボトルメール (`まろん｡` への入口) |
| 5 | 波打ち際 | `links.html` (アカウント、支援) |
| 6 | 砂浜 | 寄せては返す波、濡れた砂、カニと貝殻、フッター |

## 配色

色は `src/styles/night.css` の `:root` にまとめています。主なものは次の通りです。

| 用途 | トークン | 値 |
| --- | --- | --- |
| 夜空 | `--sky` | `#070b22` |
| 海 (沖から岸へ) | `--sea-1` / `--sea-2` / `--sea-3` | `#0b1638` / `#12245a` / `#1c3a86` |
| ウィンドウ | `--window` / `--bar` | `#0d1533` / `#1c3a86` |
| 枠と月 | `--frame` / `--moon` | `#fff6d5` |
| 見出し | `--moon-gold` | `#ffe08a` |
| リンク | `--link` / `--visited` | `#8fd8ff` / `#c3a6ff` |
| 砂 (夜) | `--sand` / `--sand-wet` | `#3b3852` / `#26243a` |

新しい色を足すときは、夜の海の中で浮かないか (昼っぽくならないか) を確かめます。

## ドットとフォント

- ドット絵は1ドット 3px です。ドット絵のデータは `src/data/pixel-icons.ts` に 16x16 の数字の並びで持ち、`src/lib/pixel-path.ts` が同じ色の横並びを1本のパスにまとめて描きます。
- 文字は PixelMplus (M+ FONT LICENSE) です。本文は PixelMplus10 の 2倍、見出しは PixelMplus12 の 2倍と 4倍です。
- 波打ち際の水深の色、手前の波、濡れた砂は、次の2つを参考にしています。
  - [Slynyrd: Pixelblog 10 - Water in Motion](https://slynyrd.com/blog/2018/10/12/pixelblog-10-water-in-motion): 波の山は谷より少し急にする。水面のきらめきは6コマ程度の単純な動きにし、光源の位置に合わせる。
  - [Godot Pixel Water shader](https://store.godotengine.org/asset/fcidade/pixel-water-godot-shader/): 水深を数段の色で分け、境目をつなぐ。波は沖から岸に向かい、岸で泡になって消える。

## 動き

| 要素 | 動き |
| --- | --- |
| 星 | 不規則にまたたく |
| 流れ星 | ときどき流れる |
| 月の反射 | 横線がゆらゆら揺れる |
| 背景の波 | ディザのシェーダーでゆっくり動く |
| 名前の下の文 | 1文字ずつ打ち込まれ、カーソルが点滅する |
| バナー | なめらかに、継ぎ目なく流れる |
| ウィンドウ | 点線の枠が広がってから開く |
| ボトル | 上下にぷかぷか揺れる |
| 波打ち際 | 波が駆け上がって引き、砂が濡れて段階的に乾く。最高到達点に泡の線が残る |
| カニ | 2コマで歩いて横切る |
