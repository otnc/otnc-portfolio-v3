# 絶対に守るルール

このサイトを直したり足したりするときに、必ず守るルールです。ここに書いたことと食い違う変更をしたくなったら、先にこのファイルを更新してから作業します。

## コンセプト

- コンセプトは「月夜のネットサーフィン」です。よく晴れた夜の海 (沖、水面、波打ち際) と、深夜のインターネットの古い OS のウィンドウを組み合わせます。
- 海は深海ではありません。月が水面に映る、晴れた日の深夜の海です。
- 見た目はコンセプトに沿わせますが、文章はコンセプトに寄せすぎません。"沖へ漕ぎだす" のような演出の言葉は入れません。
- 昼の砂浜のような明るい色は使いません。砂や波も月明かりの夜の色にします。

## 文言と表記

- サイトの文言は日本語です。例外は `/ca/` のカタルーニャ語ページだけです。
- 表示名は `otoneko.` です。漢字の `音猫｡` はどこかに必ず残します (今は自己紹介とフッター)。
- 読み仮名の行 (`おとねこ / otnc`) は表示しません。
- `Oto Lab` と表記します。小文字の `oto-lab` は URL や ID のときだけ使います。
- `otoho.me` は手放す予定のドメインなので、リンクしません。Oto Home は `github.com/oto-home` に向けます。
- UI に出すパスはスラッシュ区切りです (`/otnc/works/`)。Windows のバックスラッシュは使いません。
- キャッチコピーは `海を潜っています:)` です。

## 載せる内容

- 作品は GitHub の pinned リポジトリをリクエスト時に取得します。手書きの作品リストは作りません。
- 作品の説明文は GitHub の Description をそのまま表示します。翻訳や上書きはしません。長さが違うので、カードでは2行で省略します。
- 作品の `Link` は GitHub の Website 欄から取ります。
- `@rin_montblank` と `montblank.fun` はアカウント一覧に入れません。ボトルメールの特別な枠から誘導します。
- コミュニティ欄、WakaTime、時刻や現在地の表示は置きません。

## ドット表現

- ドット絵 (アイコン、スプライト、星、月、波、カニなど) の1ドットは 3px にそろえます (CSS の `--dot`)。例外は自分のアイコンのディザだけです (粗いと線が読めないため)。
- ドット絵は回転させたり、整数倍以外に拡大縮小したりしません。ドットがにじみます。
- 文字は PixelMplus をマス目の整数倍で使います。本文は PixelMplus10 を 20px、見出しは PixelMplus12 を 24px と 48px です。欧文も同じフォントです。
- ウィンドウの角は、ドットの欠けた形を保ちます。`box-shadow` で角を四角く塗らず、影は `filter: drop-shadow()` で付けます。
- 色の境目に付ける凸凹は、なめらかにうねる線にします。ザラザラした点描にはしません。

## 動き

- アニメーションは基本的に `steps()` でカクカク動かします。
- 例外は流れるメッセージのバナーです。`linear` でなめらかに流し、端から端まで途切れず、継ぎ目も見せません。最初は先頭のメッセージが画面中央に来ます。
- `prefers-reduced-motion` のときは、ループするアニメーションを止めます。
- 画面外のループアニメーションは止めます (`.is-paused`)。

## 技術

- Tailwind は使いません。React も、必要になるまで入れません。
- ページ間で CSS を混ぜません。共通のものは `src/styles/night.css`、部品だけのものは各 `.astro` の `<style>` に置きます。
- 部品はセクションごとに分け、ページは部品を並べるだけにします。詳しくは [architecture.md](architecture.md) を見てください。
- Cloudflare は `devuloper` アカウントを使います。ゾーン (otoneko.cat、otnc.dev) も Pages プロジェクトもここです。`mofumofupop` アカウントは mofumofupop の GitHub org 専用なので使いません。
- 正規のドメインは `otoneko.cat` (www なし) です。`www.otoneko.cat`、`otnc.dev`、`www.otnc.dev` は 301 で `otoneko.cat` に転送します。
- `/ca/` のカタルーニャ語ページは .cat ドメインの要件のために置いています。消しません。プロフィールの翻訳にはせず、カタルーニャ語と文化の紹介として独立させます。

## リポジトリ

- コード、識別子、コメント、コミットメッセージは英語です。ドキュメント (`docs/`) は日本語です。
- コミットに `Co-Authored-By` などの生成ツールの署名は付けません。
- コミットは変更の単位ごとに細かく分けます。
